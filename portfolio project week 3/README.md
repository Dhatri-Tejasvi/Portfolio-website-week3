# My Portfolio

A simple personal portfolio website built with HTML and CSS, made for my Developers Arena internship submission.

## ✨ Features
- About, Skills, and Contact sections
- Responsive design with a mobile hamburger menu
- Hover effects and smooth scroll navigation
- Time-based greeting message (Good morning / afternoon / evening)
- Dark mode toggle that remembers your choice (Local Storage)
- Live character counter on the message field
- Real-time contact form validation with error messages
- Back-to-top button that appears while scrolling

## 🛠️ Built With
- HTML5
- CSS3 (Flexbox & Grid)
- JavaScript (DOM manipulation, event listeners, Local Storage)
- Google Fonts

## 🚀 Getting Started
1. Clone or download this repository.
2. Open the folder in VS Code.
3. Right-click `index.html` → **Open with Live Server** (or just double-click `index.html` to open it in a browser).
